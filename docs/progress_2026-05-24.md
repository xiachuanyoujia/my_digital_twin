## 一、3D模型渲染修复

### 1.1 自适应顶点分类修复
- **问题**：`computeAdaptiveThresholds()` 从未被调用，所有顶点被分类为 "torso"
- **修复**：在顶点分类循环前添加采样通道 (mecha.js:279-299)，先收集 2000 个顶点样本计算自适应阈值，再进行分类

### 1.2 程序化人体模型 (mecha.js `createProcedural()`)
- **问题**：GLB 模型 (RobotExpressive.glb) 无法正常渲染
- **方案**：完全替换为 Three.js 基础几何体拼装的人体模型
  - 头部：球体 (SphereGeometry, r=0.18) + 眼睛
  - 躯干：锥形圆柱 (CylinderGeometry, h=0.70)
  - 髋部：扁平盒子 (BoxGeometry)
  - 四肢：圆柱体 (CylinderGeometry) 通过 `makeLimb()` 在两关节点间生成
  - 手脚：球体 (r=0.05) + 小盒子

### 1.3 几何体偏移修复
- **问题**：头/躯干/髋部几何体统一使用 `-pivot` 偏移，导致这三部分全部渲染在地面原点 (0,0,0)
- **根因**：`makeLimb()` 将网格放在世界空间位置 (mid)，`-pivot` 对其正确；但头/躯干/髋的几何体内容在本地原点，需要 `worldCenter - pivot` 偏移
- **修复**：头/躯干/髋使用 `C.head/C.torso/C.hip - pivot` 计算偏移，肢体保持 `-pivot`

### 1.4 手臂 restDirs 修正
- **问题**：`restDirs.upperArmL/R = (-0.7, -0.3, 0)` 但实际圆柱体几何方向为 `(0, -1, 0)`，旋转计算基准方向错误
- **修复**：改为 `(0, -1, 0)` 匹配实际几何体

### 1.5 子段动态重定位
- **问题**：肢体缩放后，子段保持固定层级偏移。如上臂拉伸到 1.2 单位但肘部枢轴仍在 0.45 单位处 → 上下臂大幅重叠
- **修复**：`updatePose()` 中，每次缩放肢体后更新子段本地位置：
  ```javascript
  this.segments.lowerArmL.position.copy(
    this.restDirs.upperArmL.clone().normalize().multiplyScalar(uaL.length())
  );
  ```
  应用于全部 8 个父子关系：上臂→前臂、前臂→手、大腿→小腿、小腿→脚

### 1.6 mpToScene 参数保护
- **问题**：校准优化器将 `scale_y` 推到 4.4 而 `scale_x/z` 保持 1.0，4.4:1 极端比例破坏模型比例
- **修复**：前端 `setMpToSceneParams()` 拒绝任何轴比例 >2:1 的参数，保持默认 (2.5, 3.5, 2.5)

### 1.7 Debug 骨架隐藏
- 默认隐藏绿色调试骨架球/线，避免与模型视觉重叠

## 二、校准流水线

### 2.1 架构
```
摄像头 → Pipeline → Landmarks → WebSocket → 前端 → mpToScene() → 模型渲染
                                                          ↓
后端校准 ← POST /calibrate/frame ←── getJointWorldPositions()
     ↓                                                    ↑
  优化参数 → GET /calibrate/params → setMpToSceneParams()
     ↓
  calibrate_and_retrain.py → 重新生成数据 → 训练YOLO → 评估
```

### 2.2 后端 API (`backend/app/api/routes/calibration.py`)
| 端点 | 方法 | 说明 |
|------|------|------|
| `/calibrate/frame` | POST | 接收前端 3D 关节位置，与存储的 landmarks 对比、累计误差 |
| `/calibrate/report` | GET | 返回逐关节 RMSE + 当前参数 |
| `/calibrate/params` | GET | 返回 `{scale_x, scale_y, scale_z, sample_count}` |
| `/calibrate/reset` | POST | 清除统计并重置参数为默认值 |

- **优化器**：每 50 帧运行最小二乘回归，EMA 平滑 (0.6)，钳位 [0.5, 6.0]，强制轴比例 ≤2:1
- **关节映射**：13 个关键点 `JOINT_TO_IDX` 对应 `BASIC_LANDMARK_INDICES` 顺序

### 2.3 前端上报 (main.js)
- 每 10 帧：调用 `mecha.getJointWorldPositions()` → POST `/calibrate/frame`
- 每 5 秒：轮询 `GET /calibrate/params` → `mecha.setMpToSceneParams()`

### 2.4 训练脚本 (`backend/scripts/calibrate_and_retrain.py`)
- CLI 参数：`--min-samples`, `--cycles`, `--timeout`, `--data-count`
- 每轮流程：采集数据 → 获取参数 → 保存 JSON → 生成合成数据 → 训练 YOLO → 评估 → 收敛检查 → 重置
